# magpie（个人维护分支）

基于 [yetone/magpie](https://github.com/yetone/magpie)，随上游合并。安装与完整功能见[上游 README](https://github.com/yetone/magpie#readme)。

## 本地定制

- **批量为项目添加技能。** 资源库中技能条目的 📁 数字徽章 → 弹窗里项目行的 ➕，一次勾选多个技能（超过 8 个出搜索框）；部分放不进（如项目已有同名自有文件夹）不中断整批，状态栏汇总“已添加 N、未放置 M”并点名清单。
- **.gitignore 只拆不写。** 放置不写 `.gitignore`，拆除时只清自己写的行，是否忽略由你决定。
- **重启后只开一个。** 开机自启（托盘）与会话恢复同时拉起时，第二个实例把参数交给第一个后退出（上游在 macOS 关闭了单实例交接）。
